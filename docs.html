Documentação da API

Guia de integração para envio de documentos avulsos (ex: via n8n).

Autenticação

Chave de API de Teste Todas as requisições devem incluir o cabeçalho x-api-key: mota-api-key-123

Essa chave garante que apenas o seu fluxo do n8n (ou sistemas autorizados) possa enviar documentos para a plataforma.

Upload de Novo Documento

Este endpoint recebe um arquivo físico e o salva na caixa de entrada de novos documentos. Ideal para processar anexos de emails recebidos de clientes, sem a necessidade de pré-atribuir a um CPF.

POST /api/upload-documento

Parâmetros (Form Data)

Parâmetro Tipo Obrigatório Descrição
documento File Sim O arquivo em si. Aceitos: PDF, JPG, JPEG, PNG (Max: 10MB).
remetente String Não O e-mail de quem enviou o arquivo (para identificação).

Exemplo com cURL

curl -X POST http://localhost:3000/api/upload-documento \ -H "x-api-key: mota-api-key-123" \ -F "documento=@/caminho/para/o/arquivo.pdf" \ -F "remetente=cliente@email.com"

Exemplo em Node.js (fetch/n8n)

const formData = new FormData(); formData.append('documento', fileInput); formData.append('remetente', 'cliente@email.com'); const response = await fetch('http://localhost:3000/api/upload-documento', { method: 'POST', headers: { 'x-api-key': 'mota-api-key-123' }, body: formData }); const data = await response.json();
